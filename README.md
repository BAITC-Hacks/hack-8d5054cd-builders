# HackAlem AI
 
MVP-платформа для хакатона **AI Sana**: превращает черновое описание бизнес-задачи в оценённую карточку, публикует её в открытом каталоге и позволяет студенческим командам откликаться, а бизнесу — вручную выбрать команду.
 
## Статус
 
В разработке
 
## Сквозной сценарий
 
1. **Черновик** — бизнес вводит краткое описание потребности/задачи.
2. **Уточнение** — AI задаёт ≥3 уместных уточняющих вопроса по недостающим полям.
3. **Карточка** — из ответов формируется редактируемая карточка, бизнес подтверждает.
4. **Рейтинг** — начисляются баллы за полноту, показывается, что повысит рейтинг.
5. **Каталог** — подтверждённая задача публикуется, позиция = рейтинг.
6. **Выбор студентов** — любая команда смотрит каталог/рекомендации, подаёт отклик.
7. **Выбор бизнеса** — бизнес сравнивает отклики, выбирает 0/1/несколько команд.
8. **Результат** — выбранная команда получает баллы за фактический прогресс.

## Формула рейтинга (0–100)
 
| Показатель | Вес | Как считать |
|---|---|---|
| Контекст и потребность | 20 | Понятно, что происходит сейчас и что нужно изменить |
| Данные и материалы | 20 | Указаны доступные данные, примеры, источники |
| Ожидаемый результат | 15 | Описан конкретный результат работы команды |
| Критерии успеха | 15 | Есть измеримые признаки принятия решения |
| Ограничения | 10 | Сроки, технологии, доступы, иные границы |
| Пользователи | 10 | Понятно, для кого решение |
| Связь с бизнесом | 10 | Есть контакт, формат консультаций |
 
**Уровни готовности:**
 
- 0–39 — черновик (видна в каталоге, помечена как «требует уточнения»)
- 40–69 — рабочая (можно откликаться, система может рекомендовать)
- 70–89 — готовая (повышенная позиция в каталоге)
- 90–100 — приоритетная (выделяется в каталоге)
Рейтинг пересчитывается после каждого подтверждённого дополнения. Низкий рейтинг не скрывает задачу и не запрещает отклик.
 
## Правила каталога
 
- Все опубликованные задачи доступны всем командам.
- Сортировка по рейтингу, фильтры по теме и уровню готовности.
- Число откликов не ограничивается.
- Выбор команды — только вручную бизнесом; автоматическое назначение запрещено.
