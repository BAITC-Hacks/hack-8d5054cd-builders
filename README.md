# HackAlem AI · Практикум бизнес-задач

Streamlit MVP для полного сценария: бизнес описывает задачу, уточняет сведения, проверяет рейтинг и публикует карточку; студенческие команды отправляют отклики, а бизнес сам выбирает одну, несколько или ни одной команды.

## Запуск

Нужен Python 3.11 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Приложение откроется в браузере. Данные хранятся только в `st.session_state` текущего процесса и сбрасываются после его перезапуска.

## Демо и OpenAI

По умолчанию `.env.example` задаёт `DEMO_MODE=true`. В этом режиме вопросы и карточка собираются локально для сценария незавершённых онлайн-заказов. Нажмите **«Вставить пример для демо»**, затем **«Проанализировать»**. Ответы-заготовки появятся в форме; их можно изменить, сформировать карточку, проверить рост рейтинга, опубликовать её, перейти в роль студенческой команды и откликнуться. Вернитесь в роль бизнеса, чтобы выбрать или отклонить отклик.

Чтобы использовать OpenAI, задайте в `.env`:

```dotenv
DEMO_MODE=false
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-4o-mini
```

Ключ берётся только из переменной окружения и не сохраняется в коде. AI возвращает JSON, а запрос ограничен таймаутом 12 секунд без повторных сетевых попыток. Если ключ не задан, ответ модели некорректен или API недоступен, приложение автоматически использует локальный сценарий. Содержимое черновиков и ответы API не записываются в логи.

## Структура

```text
app.py             Streamlit UI, роли и сценарии
src/ai.py          OpenAI JSON-вызовы и локальные заглушки
src/rating.py      Чистая детерминированная формула рейтинга
src/models.py      Структуры карточки, отклика и команды
data/seed.json     Пять черновиков, карточек, команд и откликов
```

Роль выбирается в сайдбаре. Авторизации нет: поле рабочего пространства бизнеса лишь отделяет список «Мои задачи», а выбор студенческой команды задаёт профиль для формы отклика. Каталог общий, без фильтров; задачи остаются доступными при любом рейтинге.

## Формула рейтинга

Баллы начисляются только по заполненности карточки, без AI. Поле с коротким ответом получает целочисленную половину веса с округлением вниз; поле, достигшее порога длины, — полный вес. Порог длины нужен для того, чтобы пустые формальные ответы не выглядели как готовая постановка. Считаются символы после схлопывания повторных пробелов.

| Поле | Вес | Для полного веса |
|---|---:|---:|
| Контекст | 10 | 35 символов |
| Потребность | 10 | 20 символов |
| Данные и материалы | 20 | 15 символов |
| Ожидаемый результат | 15 | 20 символов |
| Критерии успеха | 15 | 20 символов |
| Ограничения | 10 | 14 символов |
| Пользователи | 10 | 10 символов |
| Контакт | 5 | 5 символов |
| Формат взаимодействия | 5 | 12 символов |
| **Итого** | **100** | — |

Уровни: 0–39 — черновик, 40–69 — рабочая, 70–89 — готовая, 90–100 — приоритетная. Название нужно для публикации, но в рейтинг не входит. Рейтинг пересчитывается во время редактирования карточки; изменения опубликованной задачи применяются по кнопке подтверждения.

## Правила каталога и выбора

- В каталоге показываются все опубликованные задачи, отсортированные от большего рейтинга к меньшему.
- Низкий рейтинг не скрывает карточку и не запрещает командам откликаться.
- Отклик содержит команду, идею, план и необязательную ссылку на прототип. Ограничения на количество откликов нет.
- Бизнес вручную выбирает или отклоняет каждый отклик. Можно выбрать несколько команд; автоматического назначения нет.
- Seed-отклики показывают работу списка решений до отправки нового предложения.

## Короткий сценарий демонстрации

1. В роли бизнеса загрузить демо-черновик, показать стартовый рейтинг и проанализировать его.
2. Проверить уточняющие ответы, сформировать и при необходимости отредактировать карточку.
3. Показать балл и подсказки, затем подтвердить публикацию.
4. Переключиться на студенческую команду, отправить идею и план через каталог.
5. Переключиться обратно в бизнес, открыть «Мои задачи» и вручную выбрать или отклонить отклик.
