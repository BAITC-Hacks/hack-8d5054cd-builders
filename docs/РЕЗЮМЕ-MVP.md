# Практикум · HackAlem AI / AI Sana

**Версия 0.5 · 23 сентября 2026 · резюме MVP**

Платформа превращает короткое описание бизнес-проблемы в понятную задачу для студентов. Бизнес уточняет сведения с AI, подтверждает карточку и повышает её позицию в каталоге. Команды предлагают решения, бизнес вручную выбирает исполнителей и принимает результаты.

## Что выполнено и проверено

- **Полный маршрут:** черновик → минимум три вопроса → десять редактируемых полей → подтверждение → каталог → отклик → ручной выбор → принятый этап.
- **Геймификация бизнеса:** рейтинг 0–100, семь групп весов из кейса, четыре уровня, паспорт готовности и подсказки с прибавкой. После правки видны прежние и новые балл/место. Низкий рейтинг не запрещает отклик.
- **Каталог и предложения:** сортировка, фильтры темы/готовности, идея, план, обязательный срок и ссылка. Сравнение откликов; бизнес может выбрать одну, несколько или ни одной команды.
- **Прогресс студентов:** план, прототип и результат дают 20/40/60 XP только после принятия бизнесом. Есть доработка и защита от повторной награды.
- **AI и резерв:** OpenAI и NVIDIA через один слой; строгий JSON и проверка точных цитат источника. При ошибке — локальный сценарий. Промпты улучшены и приложены для защиты.
- **Интерфейс:** светлая тема, спокойные цвета, понятные шаги, примеры в полях, компактные карточки и визуальная расшифровка рейтинга.
- **Данные:** по пять черновиков, карточек, команд и предложений. Исходный каталог содержит все четыре уровня готовности.

**Проверки:** 142 теста без внешней сети прошли, включая сквозные сценарии Streamlit AppTest. Реальный OpenAI вернул 8 вопросов и собрал 10 полей с проверенными источниками: рейтинг 20 → 100. NVIDIA в финальном прогоне не проверялся. В браузере отдельно пройден весь сценарий до приёмки плана: 10 → 80 → 100 баллов, место 4 → 2 из 6, предложение со сроком, ручной выбор и 20 XP после подтверждения.

## Архитектура и границы

**Python 3.11+ → Streamlit → модули AI, рейтинга, каталога и прогресса → `st.session_state`.** Один `app.py`, структуры в `src/models.py`, синтетические данные в `data/seed.json`. Ключи читаются из окружения; `.env` исключён из Git.

Данные общие для ролей **только внутри одной сессии браузера**. Нет БД и авторизации. Рейтинг оценивает полноту, смысл и факты подтверждает человек. Ссылки `example.com` в исходных данных — демонстрационные. Это ограничения выбранного MVP.

## Обязательное демо до пяти минут

Использовать карточку **«Удобное оформление онлайн-заказов»**: слабый черновик → вопросы → карточка без данных на **80** → публикация на месте **4/6** → добавить данные и подтвердить → **100**, место **2/6** → предложение команды → ручной выбор бизнеса → принятие плана, **0 → 20 XP**. Позиции рассчитаны для свежей сессии с пятью исходными задачами. Главный акцент — геймификация бизнеса, **25 баллов** в оценке жюри.
